    Class OfflineModelService

    Offline Model Service Handles interaction with local LLMs via Ollama.

    SETUP INSTRUCTIONS:

    1. Install Ollama: macOS: https://ollama.com/download/Ollama.dmg Windows: https://ollama.com/download/OllamaSetup.exe Linux: curl -fsSL https://ollama.com/install.sh | sh

    2. Download a model (pick one based on your RAM): Small (815MB, 1GB RAM): ollama pull gemma3:1b Medium (3.3GB, 8GB RAM): ollama pull gemma3 Large (8.1GB, 16GB RAM): ollama pull gemma3:12b

    3. Start Ollama (usually starts automatically): ollama serve

    4. Enable in Milla-Rayne: Edit .env: ENABLE_LOCAL_MODEL=true PREFER_LOCAL_MODEL=true

    That's it! Your chats will now use local inference for privacy.
